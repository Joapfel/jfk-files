16 July 1958

MEMORANDUM FOR: Chief, W/III

PROJECT: Project LIVET

REFERENCE: Memorandum for Chief, E/Czechoslovakia from Chief, W/III, subject as above, dated 2 July 1958

Before its suspension in January 1958, the LIVET phase of Project LIVET provided biographic data on the members of the Czech Legation in Mexico City which ER/C found useful in the evaluation of these individuals as possible targets. If the LIVET phase of the project is resumed, it is anticipated that it would continue to provide similarly useful information. For this reason ER/C is interested in seeing Project LIVET renewed.

PHILIP BROWN
Chief, E/Czechoslovakia
