Applicant Coding Data. ID; application number; name; date of birth; date coded. Six-digits must contain 20-digits. Month, day, year. The data above (items 2 through 5) will be filled in when coding an applicant for the first time. This form is then attached to Form 1962, Master Qualifications Coding Record.

Language Coding Data — Form 444C. ID; employee number; name, 3 letters; language data code: base code, R, W, P, S, U, T, year. Date submitted; date of birth. Month, day, year. When Form 444C denotes no language competence, enter the following in item 4: “NO++LANGUAGE” (12-digits).

Language Proficiency Test Data. ID; employee number; name, 3 letters; code, C-A-D; language data before test, base code; Code No. 1; Code No. 2.
