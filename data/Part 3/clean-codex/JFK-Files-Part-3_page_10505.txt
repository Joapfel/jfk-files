9:12 PM NITEL, March 25, 1975. JLC.

To: Director.

Attention: Budget and Accounting Section.

From: Memphis.

Senate Select Committee on Intelligence Activities. Rebutel March 24, 1975.

Memphis office uses approximately 25 percent of one supervisor's time in the security field, 20 percent on internal security, and 5 percent on counterintelligence.

In addition, six agents are utilized. The following shows the percentage of total time spent by these agents in this field:

Agent A: security cases, 100 percent; internal security, 100 percent; counterintelligence, 0 percent.

Agent B: security cases, 75 percent; internal security, 50 percent; counterintelligence, 25 percent.

Agent C: security cases, 50 percent; internal security, 50 percent; counterintelligence, 0 percent.

Agent D: security cases, 50 percent; internal security, 25 percent; counterintelligence, 25 percent.

Agent E: security cases, 25 percent; internal security, 25 percent; counterintelligence, 0 percent.

Agent F: security cases, 25 percent; internal security, 0 percent; counterintelligence, 25 percent.
