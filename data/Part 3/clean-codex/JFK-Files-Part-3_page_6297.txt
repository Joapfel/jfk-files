United States Government Memorandum

To: Mr. J. B. Adams  
From: Legal Counsel  
Subject: SENSTUDY 75  
Date: October 21, 1975

On October 20, 1975, James Dick, staff member for the captioned Committee, who is in charge of the hearings on mail openings, advised that the public session is to be held on October 24, 1975, and furnished a copy of what that Committee considers to be the issues raised by the Bureau's mail opening programs. Copy is attached. Additionally, he advised that the Committee plans to refer to the eight Bureau mail opening programs by numerical code names in their public hearing. He furnished the following code numbers with the Bureau code name:

Code name number 1: Z-Coverage  
Code name number 2: Sam Survey  
Code name number 3: Gus Survey  
Code name number 4: Sun Survey  
Code name number 5: Joe Survey  
Code name number 6: Chiprop Survey  
Code name number 7: Chiclet Survey  
Code name number 8: Chican Survey

Dick advised that this will be used by the Senators during the hearing and that Mr. Wannall and Mr. Branigan, who will testify, should be familiar with these numerical definitions.

Recommendation:

Intelligence Division should review the attached issue paper presented by the Committee to be familiar with the questions raised by the Bureau's mail opening programs as seen by the Committee.
