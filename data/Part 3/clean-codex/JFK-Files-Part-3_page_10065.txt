25 March 1975.

NR 005 ME PLAIN.

9:12 PM NITEL, 25 March 1975, JLC.

To: Director, attention Budget and Accounting Section. From: Memphis.

Senate Select Committee on Intelligence Activities.

Rebutel, 24 March 1975.

Memphis Office uses approximately 25 percent of one supervisor's time in the security field, 20 percent on internal security, and 5 percent on counterintelligence.

In addition, six agents are utilized. The following shows the percentage of total time spent by these agents in this field:

Agent A: 100 on security cases, 100 on internal security, 0 on counterintelligence.
Agent B: 75 on security cases, 50 on internal security, 25 on counterintelligence.
Agent C: 50 on security cases, 50 on internal security, 0 on counterintelligence.
Agent D: 50 on security cases, 25 on internal security, 25 on counterintelligence.
Agent E: 25 on security cases, 25 on internal security, 0 on counterintelligence.
Agent F: 25 on security cases, 0 on internal security, 25 on counterintelligence.

In addition to the one-fourth supervisor time, this office uses the equivalent of three and one-fourth agents in the security.
