From Charlotte (100-00)

Senate Select Committee on Intelligence Activities.

REBULET—March 24, 1975.

Charlotte Division has one supervisor assigned full time to security matters; no other supervisory personnel handle security.

There are 3 headquarters agents assigned full time to security matters and one additional headquarters agent assigned 75 per cent to security investigations. One resident agent is assigned 75 per cent to security matters, 4 additional resident agents are assigned 50 per cent to security matters, and 9 additional resident agents are assigned from 5 to 15 per cent of their work in security classifications.

No supervisory or agent personnel assigned to counter-intelligence program, which was discontinued per Bureau instructions in 1971.

End
