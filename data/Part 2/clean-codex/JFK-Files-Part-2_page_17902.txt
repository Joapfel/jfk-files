To: Director. From: Memphis. Attention: Budget and Accounting Section.

Senate Select Committee on Intelligence Activities.

Rebutel, 24 March 1975.

Memphis Office uses approximately 25 percent of one supervisor's time in the security field, 20 percent on internal security, and 5 percent on counterintelligence.

In addition, six agents are utilized. The following percentages of total time are spent by these agents in this field:

Agent A: 100 percent on security cases, 100 percent on internal security, 0 percent on counterintelligence.
Agent B: 75 percent on security cases, 50 percent on internal security, 25 percent on counterintelligence.
Agent C: 50 percent on security cases, 50 percent on internal security, 0 percent on counterintelligence.
Agent D: 50 percent on security cases, 25 percent on internal security, 25 percent on counterintelligence.
Agent E: 25 percent on security cases, 25 percent on internal security, 0 percent on counterintelligence.
Agent F: 25 percent on security cases, 0 percent on internal security, 25 percent on counterintelligence.
