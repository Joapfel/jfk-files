6. Re-supply arrangements:

If carbons are lost: The agent writes a cover letter to the Madrid address in the normal manner. Absence of an S/W message indicates loss of the carbons, and the agent is to expect the next letter he receives to be a re-supply of carbons in the form of the letter itself.

If developer is lost: The agent so indicates in a letter to Madrid, in S/d; re-supply will take place through one of the three dead drops which the agent has been told to locate and report as soon as possible by S/W.
