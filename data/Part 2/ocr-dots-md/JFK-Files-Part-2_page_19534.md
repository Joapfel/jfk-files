Milwaukee files do reflect additional information concerning LEA BETTY ZELDIN, Security Index subject. This information concerned data from a confidential source abroad (Italian Armed Forces Intelligence Service) to the effect that ZELDIN, while in Bologna, Italy in 1966, attended meetings and participated in rallies of the Italian Communist Party. This information has not been included in the enclosed LHM inasmuch as it is classified "Secret" and would therefore necessitate classification of LHM as "Secret". It is felt that ZELDIN is adequately described through public sources as set forth in LHM as an anti-Vietnam demonstrator.
